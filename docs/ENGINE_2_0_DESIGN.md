# EDQ Engine 2.0 設計メモ alpha4

## 目的

第1話専用コードを増やすのではなく、第100話まで各話データを追加して使える共通エンジンを作る。

## alpha4で追加した層

1. `StoryCommands`：ストーリー作成者が使う共通命令
2. `StoryCompiler`：各話データを標準stepへ変換
3. `StoryRegistry`：変換済みの話数を登録
4. `StoryEngine`：標準stepだけを実行

この順序により、各話の書き方を将来改善しても、実行部分を大きく変更しなくてよい。

## 安全方針

- Ver.1.7を比較基準として保持する。
- S001とCSSは安定確認済みの内容を維持する。
- 一段階ごとに最後まで動くことを確認する。
- 共通化できる処理だけをEngineへ入れる。
- キャラクター固有・話数固有の意味をEngineに判断させない。

## 次段階

キャラクターの名前、画像フォルダ、利用可能なポーズ番号をストーリーから分離し、CharacterCatalogとして登録する。
